# MyShotLog logo

- `MyShotLog-logo.svg`: full horizontal logo, transparent background.
- `MyShotLog-icon.svg`: standalone book/target/pistol symbol, transparent background.
- `MyShotLog-logo-monochrome.svg`: single-colour version using `currentColor`.
- `MyShotLog-preview.png`: preview on the app background.

All SVG elements are vectors. Lettering is converted to paths; no fonts or raster images are embedded. Colours: forest green `#315d43`, charcoal `#233329`, muted gold `#bc9864`. Preserve proportions and use on a light background; use the monochrome version for other colour schemes.

PNG exports match the three SVG variants, have transparent backgrounds, and are 2400 pixels wide. The icon is 2400 × 2400 pixels.
