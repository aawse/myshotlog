# MyShotLog identity

A geometric shield represents protection of the journal. Concentric target rings and aligned sights express precision; two short journal lines retain the connection to logging results. The wordmark uses bold outlined lettering. The only accent is the muted-gold centre of the target.

- `MyShotLog-logo.svg`: horizontal logo, 761 × 256, transparent background.
- `MyShotLog-icon.svg`: standalone shield and target, 256 × 256.
- `MyShotLog-logo-monochrome.svg`: one-colour logo using `currentColor`; target details are transparent mask cut-outs.
- Matching PNG files: transparent, 2400 pixels wide. The icon is 2400 × 2400.
- `MyShotLog-preview.png`: colour, standalone icon and reversed monochrome examples.

Colours: forest green `#315d43`, charcoal `#233329`, muted gold `#bc9864`. Use the colour logo on light backgrounds and a contrasting monochrome version on other backgrounds. Preserve proportions and leave clear space around the mark. The SVGs contain only vector artwork and outlined lettering; no fonts or raster images are embedded.

Regenerate assets from the project root with `node scripts/generate-brand.mjs`. The script uses the bundled DejaVu Sans Bold font; its copyright and redistribution terms are in [the font licence](../../lib/pdf/assets/LICENSE.txt). No system font installation is needed.
